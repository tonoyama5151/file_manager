# ファイルマネージャー（Android）

端末内のファイル整理と、pCloud の参照ができる Android アプリです。PC なしでスマホだけでビルド・導入できるよう、GitHub Actions で APK を自動作成します。

## インストール

1. スマホのブラウザで次の URL を開くと、最新の APK がダウンロードされます。
   https://github.com/tonoyama5151/file_manager/releases/latest/download/FileManager.apk
2. ダウンロードした `FileManager.apk` を開いてインストールします（初回は「提供元不明のアプリ」の許可が必要です）。
3. 初回起動時に「全ファイルへのアクセス」を許可してください。

`main` ブランチに変更を push するたびに自動でビルドされ、上の URL が新しい版に置き換わります。毎回同じ鍵で署名しているので、上書きインストールで更新できます。

## 機能

### ホーム
- ストレージ（使用量）、ダウンロード、ストレージ分析、クラウドのタイル
- ジャンル別タイル：画像・オーディオ・動画・ドキュメント・アプリ(APK)・圧縮ファイル・新着ファイル（直近7日）
- ジャンル一覧はグリッド／リスト切替、並べ替え、複数選択で共有・コピー・移動・削除・名前変更
- ストレージ分析：ジャンル別の使用量内訳と、大きいファイル上位50件（その場で削除可）

### サムネイル
- 画像・動画・PDF（1ページ目）・音楽のジャケット・APKのアイコン
- pCloud 上の画像・動画もサムネイル表示

### 端末
- フォルダ閲覧（メインストレージ / SD カード切替、パンくずリスト、グリッド／リスト切替）
- 並べ替え（名前・更新日時・サイズ・種類）、隠しファイルの表示切替
- 長押しで複数選択 → コピー・移動・削除・名前変更・共有・詳細
- 新しいフォルダの作成
- **圧縮**：選択したファイル・フォルダを zip に
- **解凍**：zip / 7z / tar / tar.gz / tar.bz2 / tar.xz / gz / bz2 / xz（Windows で作った zip の日本語ファイル名にも対応）

### pCloud（参照のみ）
- フォルダ閲覧
- ファイルを開く（一時ダウンロードして他アプリで表示）
- 端末に保存（`Download/pCloud/` に保存）
- 米国・欧州どちらのアカウントでも自動判別

## pCloud の初期設定（1回だけ）

1. pCloud 開発者ページの [My Apps](https://docs.pcloud.com/my_apps/) で新しいアプリを作成し、**Client ID** を控えます。
2. アプリの「pCloud」タブで Client ID を貼り付け、「ブラウザでログイン」を押します。
3. ブラウザで pCloud にログインして許可したら、アプリに戻ります。数秒で一覧が表示されます。

うまくいかない場合は、画面下部の「認証コードで接続」から、Client Secret と表示された認証コードで接続できます。

## 補足

- 署名鍵（`app/signing.keystore`）はリポジトリに含めています。個人利用を前提とした簡易な運用です。
- 「全ファイルへのアクセス」権限を使うため、Google Play での公開は想定していません。
